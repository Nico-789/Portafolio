Sistema Inteligente de Recomendación de Recetas con IA

La aplicación permite recomendar platos a partir de ingredientes disponibles, optimizando recursos y ofreciendo instrucciones detalladas de preparación. Sistema de Automatización de Pagos con Playwright

Desarrollo de una solución de automatización contable enfocada en optimizar el registro de pagos en Siigo mediante tecnologías RPA. El proyecto fue desarrollado con Python y Playwright, permitiendo automatizar la navegación web, validación de información y carga de datos desde archivos CSV de forma rápida y precisa. Además, se implementó una lógica robusta de manejo de excepciones y automatización de formularios para reducir tiempos operativos, minimizar errores manuales y mejorar la eficiencia de los procesos empresariales.
